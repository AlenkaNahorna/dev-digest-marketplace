# Spec-driven development

> Initial draft. The plugin owner refines the workflow.

1. Write or refine the spec: problem, goals, non-goals, acceptance criteria.
2. Derive a plan and a task list from the spec; stop for review.
3. Implement task by task, tracing each change back to the spec.
