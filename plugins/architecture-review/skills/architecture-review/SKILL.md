# Architecture review

> Initial draft. The plugin owner refines the checklist.

1. Summarize the system context and the decision under review.
2. Walk the checklist: boundaries, data ownership, failure modes, security, operability, cost.
3. Output findings ranked by severity and, if requested, an ADR draft.
